# Roadmap

## 0.2 — adapters and governance

- Publish a JSON Schema for both artifact versions.
- Add lightweight browser and server event adapters with explicit consent hooks.
- Add weight-set files with ids, hashes, and migration checks.
- Add sensitivity views showing which assumptions drive a cohort result.

## 0.3 — decision quality

- Add cluster-aware uncertainty for repeated sessions.
- Add pre-registered decision thresholds and non-inferiority guardrails.
- Add accessibility and trust signals without collapsing them into one opaque number.

The roadmap deliberately excludes identity tracking and a hosted data collector. Open an issue with a falsifiable use case before proposing a new composite metric.
