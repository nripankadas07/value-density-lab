# Research provenance

The implemented equations and three domain archetypes originate in Dr. Nripanka Das's January 2026 article, [Beyond the Attention Economy: The Value Density Framework for Digital Platform Success](https://www.linkedin.com/pulse/beyond-attention-economy-value-density-framework-digital-das-5wiqc).

The article connects the framework to Information Foraging Theory, regret regulation, Goodhart's Law, the HEART framework, and the Goldilocks hypothesis. Consult the article's references for the primary literature.

This repository contributes the event contract, validators, deterministic reference algorithms, bootstrap summaries, local reporters, threat boundary, and executable tests. It does not copy another analytics SDK and does not claim that this particular parameterization has been externally validated.
