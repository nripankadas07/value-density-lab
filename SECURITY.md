# Security policy

Report vulnerabilities privately through GitHub's security advisory interface. Do not open a public issue for an exploitable path, data disclosure, or report injection.

Value Density Lab processes local JSONL and writes local reports. Treat event ledgers as sensitive analytics data: use rotating pseudonyms, minimize fields, restrict filesystem access, and inspect artifacts before sharing. The tool provides validation and HTML escaping, not a privacy compliance program.

Supported version: the latest `0.1.x` release.
